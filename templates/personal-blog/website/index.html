Notes from building in public

September 15, 2026

Today I shipped the first version of a markdown blog that stores posts in PostgreSQL and renders them without a JavaScript framework on the front page.

The goal is simple: write in markdown, publish with an API call, and give visitors a fast page that looks like a blog — not a dashboard.

What you control

  • Site title and tagline via env vars
  • Post slugs generated from titles
  • Draft support through the published flag

Publishing stays in the terminal

Protected admin route. Send JSON. The post appears on your homepage. That is the whole workflow for v1.

curl -X POST https://your-blog.up.railway.app/admin/posts \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_KEY" \
  -d '{"title":"Hello","body_markdown":"# Hi\n\nFirst post."}'

Deploy the template on Railway

Add PostgreSQL, set ADMIN_API_KEY, enable public HTTP. Your blog can be live before lunch.
