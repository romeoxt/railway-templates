When this template makes sense

You run a personal blog, a small SaaS landing page, or a community site and want a dashboard you control. You do not need ad attribution or session replay yet. You do want to know which pages people read and whether that newsletter link worked.

Railway keeps the infrastructure simple: one Postgres service, one Umami container, a public URL, done. The template repo documents variables and the first-login steps so you are not guessing.

Setup overview

1 · Add PostgreSQL with a volume

Data must survive redeploys. Attach persistent storage to the database service.

2 · Add Umami Docker image

Image: ghcr.io/umami-software/umami:postgresql-latest. Connect DATABASE_URL and generate an APP_SECRET.

3 · Log in and change defaults

Default credentials are documented in the README. Change the admin password immediately after first login.

4 · Add the tracking script to your site

Umami generates a script tag per website you register in the dashboard.

Integration note: This repository is a deployment guide, not a fork of Umami. The running app comes from the official container image.
