# Project brief — Simple Analytics marketing site

- **Business:** Simple Analytics (Railway template)
- **What it does:** Self-hosted page view tracking with a browser dashboard
- **Audience:** Indie developers, hobby site owners, MVP builders
- **Visitor goal:** Understand if this is lighter than GA and how to deploy it
- **Primary conversion:** Deploy on Railway / open GitHub template
- **Pages:** Single landing page
- **Stack:** Plain HTML, CSS, minimal JS
- **Brand personality:** Quiet, precise, honest, practical, warm
- **Aesthetic:** Editorial minimal with data-panel motif
- **Type:** Fraunces + IBM Plex Sans
- **Palette:** Warm paper `#f6f1ea`, terracotta accent `#c45c3e`, charcoal panels
